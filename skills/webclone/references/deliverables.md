# Deliverables and templates

Standard artifacts per clone. Paths are relative to the clone project root; `<site>` is the slug from `.webclone.json`.

```
docs/research/<site>/
  NOTES.md                    required
  TEARDOWN.md                 complex/interactive sites
  recon/                      recon-site output (source and clone)
    original-recon.json, original-summary.md, screenshots/original-{1440,768,390}.png
    clone-recon.json, screenshots/clone-*.png
    visual-diff-<width>.json, screenshots/visual-diff-<width>.png
    asset-manifest.json       asset-harvest map (originalUrl -> localPath)
    routes/, routes-clone/    route-crawl maps + per-route screenshots
    interactions/, interactions-clone/   interaction-probe evidence
    network/                  XHR/fetch capture + fixtures/
    sourcemaps/               sourcemap-hunt results
    baseline/                 raw WebGL replay + evidence (effect-extraction.md)
  design-dna.json             visual/remix modes (design-dna.md)
CLONE_REPORT.md               compare-recon output
CLONE_AUDIT.md                audit-clone output
```

```markdown
## Run
cd <projectDir> && npm run dev

## Changes from the source
- Tracking removed: ...
- ...

## Source vs clone
| Module | Source behavior | Clone implementation | Difference / trade-off | Evidence |
|---|---|---|---|---|

## Clone scores
(see assessment.md)

## Replace before deploying
- Logos / trademarks -> files
- Copy -> files
- Photography / video -> public/sites/<site>/...

## Verification
- [ ] Runs locally, zero console errors
- [ ] Screenshots compared with the source (recon/screenshots/)
- [ ] route-crawl maps for source and clone (multi-page sites)
- [ ] interaction-probe evidence for hover/click/scroll/canvas (interactive sites)
- [ ] visual-diff report per key width
- [ ] audit-clone --strict passes
- Not verifiable (state honestly): ...
```

## TEARDOWN.md (complex sites)

Every conclusion cites real source lines.

- **0. One-sentence essence**
- **A. Real technical teardown** by pillar (rendering, compositing, physics, interaction, audio); each item cites file:line and an evidence grade `SOURCE` / `PARTIAL` / `GUESS` (effect-extraction.md)
- **B. Second-hand analysis check** (when an AI/blog analysis exists): `claim | real source | accuracy ✅/⚠️/❌ | note`
- **C. Transferable method**: general technique / site-specific / clone path

## CLONE_REPORT.md

Generated by `compare-recon.mjs`; add a human summary on top:

```markdown
## Summary
- Complexity / mode:
- Overall fidelity (visual-diff score per width):
- Best use: local study / further remix / deployable demo / teardown only
## Known gaps
## Next upgrades
```

## CLONE_AUDIT.md

Generated by `audit-clone.mjs`. Check: fidelity defects (fonts/images/colors), tracking scripts and pixels, source brand residue (expected in faithful mode, a defect in remix mode), TODO/placeholder text, external URLs still pointing to the source or uncontrolled third parties.

## Finish

- Stop the dev server and any background processes you started.
- Leave `docs/research/<site>/` in place; it is the evidence for every claim in the delivery.
