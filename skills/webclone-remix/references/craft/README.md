# Craft references

Brand-agnostic rules a competent designer applies on top of any `DESIGN.md`. Read only the files the task needs.

| File | Read when |
|---|---|
| `anti-ai-slop.md` | Any remixed marketing/landing page (always) |
| `typography.md`, `typography-hierarchy.md` | Changing fonts or type scale |
| `color.md` | Changing the palette |
| `accessibility-baseline.md` | Any interactive UI (always check before delivery) |
| `state-coverage.md` | Forms, lists, dashboards, anything stateful |
| `form-validation.md` | The page has a form |
| `laws-of-ux.md` | Pricing, onboarding, navigation, or choice-heavy layouts |

Source: `craft/` from [nexu-io/open-design](https://github.com/nexu-io/open-design) (Apache-2.0), several files adapted there from [refero_skill](https://github.com/referodesign/refero_skill) (MIT). OpenDesign-specific tooling references were removed. See the repository's `THIRD_PARTY_NOTICES.md`.
