# Starter themes

Ten palette + font pairings from `theme-factory` in [anthropics/skills](https://github.com/anthropics/skills) (Apache-2.0). Use one as a starting point when the user has no brand of their own, then adapt it with `craft/color.md` and `craft/typography.md`. The listed fonts are presentation defaults; for the web, pick close Google/variable fonts and load them with `next/font`.
